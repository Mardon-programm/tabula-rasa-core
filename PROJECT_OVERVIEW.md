# TR-Core — Project Overview

An **experimental autonomous cognitive architecture** for studying how a machine develops and adapts its understanding of the world from experience.

**Status:** Active R&D
**Type:** Cognitive Architecture / Artificial Intelligence Research
**Version:** 0.1
**Research Stage:** Experimental
**Core Principle:** Experience → Prediction → Error → Exploration → Learning → Memory → World Model → Planning → Action

## 00 — 🏠 PROJECT HOME

### What is TR-Core?

TR-Core (Tabula Rasa Cognitive Core) — это **экспериментальная автономная когнитивная архитектура**, исследующая возможность создания искусственного агента, который начинает с минимального количества априорного знания и постепенно формирует собственные представления о мире через взаимодействие со средой.

Это **исследовательский инструмент, а не заявление об AGI**: цель — проводить контролируемые эксперименты о том, как непредобученная система строит и адаптирует внутреннюю модель мира, и — что важнее — *какие именно механизмы* дают функциональную ценность.

Без предобученных нейровесов, без эмбеддингов, без LLM.

### Research Question

> Can a non-pretrained cognitive architecture detect changes in environmental dynamics and adapt its internal transition model using prediction error and experience-driven learning — and which of its mechanisms (memory, curiosity, self-model, adaptation) contribute to that?

**Null hypothesis (явно на столе):** на достаточно простой среде простой адаптивный обучатель переходов может сравняться с полной архитектурой. Это считается валидным и информативным результатом, а не провалом.
