## Основные концепции

### Когнитивные системы (10 модулей)

| Система | Файл | Назначение |
|---------|------|-----------|
| Substrate | `core/substrate.py` | Сенсорное восприятие и обработка сигналов |
| Graph Brain | `core/graph_brain.py` | Нейроподобное обучение ассоциациям |
| World Model | `core/world_model.py` | Представление окружения |
| Prediction Engine | `core/prediction.py` | Предсказание состояния |
| Adaptation | `core/adaptation.py` | Обучение, управляемое ошибками |
| Curiosity | `core/curiosity_rl.py` | Мотивация исследования |
| Memory | `memory/` | Хранилище эпизодической + семантической памяти |
| Self-Model | `models/self_model.py` | Метапознание |
| Planner | `planner/tree_search.py` | Планирование действий |
| Development | `core/developmental_stage.py` | Прогрессия стадий |

### Цикл агента

Каждый шаг: **Восприятие → Предсказание → Сравнение → Адаптация → Запоминание → Действие**

### Ключевые метрики

- **Точность предсказания** - Насколько хорошо агент предсказывает
- **Ошибка калибровки** - Уверенность vs фактическая производительность
- **Сигнал концептного дрейфа** - Обнаружение изменений окружения
- **Оценка любознательности** - Мотивация исследования
- **Статистика памяти** - Использование буферов эпизодической/семантической памяти
- **Состояние самомодели** - Самосознание агента

## Решение проблем

### Агент не обучается
- Проверьте метрику точности предсказания
- Проверьте, что размер модели мира растёт
- Убедитесь, что окружение детерминировано

### Высокий сигнал концептного дрейфа
- Может указывать на реальное изменение окружения
- Проверьте, что обнаружение дрейфа работает
- Просмотрите параметры скорости обучения

### Память растёт слишком быстро
- Отрегулируйте лимит буфера эпизодической памяти
- Проверьте сохранение семантической памяти
- Просмотрите интервал консолидации
