# TR-Core Резюме реализации

## Обзор проекта

TR-Core (Tabula Rasa Core) - это полная платформа развивающегося когнитивного агента для исследований, демонстрирующая автономное непрерывное обучение, формирование модели мира, предсказание и метапознание без предварительно обученных весов.

## Компоненты системы

### 1. Слой восприятия (`core/substrate.py`)

**Назначение:** Преобразование необработанных наблюдений в дискретные, сегментированные сигналы

**Реализация:**
- Сегментация сигналов на основе энтропии
- Буферизация наблюдений и окнование
- Расчёт плотности информации
- Обнаружение временных паттернов сигнала

**Ключевой класс:** `SensorySubstrate`

### 2. Слой нейроподобных ассоциаций (`core/graph_brain.py`)

**Назначение:** Изучение и представление ассоциаций состояний

**Реализация:**
- Динамический разреженный направленный граф
- Обучение синаптических весов (подобное Хеббийскому)
- Снижение и отсечение весов
- Отслеживание возраста синапсов и активаций

**Ключевой класс:** `DynamicSparseGraph`

### 3. Модель мира (`core/world_model.py`)

**Назначение:** Комплексное представление окружения

**Компоненты:**
- Отслеживание сущностей (свойства и уверенность)
- Отношения (пространственные, причинные, временные)
- Статистика переходов (правила состояние→состояние→состояние)
- Квантификация неопределённости (эпистемическая, алеаторическая, модель)
- Причинные связи

**Ключевой класс:** `WorldModel`

### 4. Механизм предсказания (`core/prediction.py`)

**Назначение:** Прогноз следующих состояний с оценкой уверенности

**Реализация:**
- Генерация предсказаний из модели мира
- Оценка уверенности
- Вероятности альтернативных исходов
- Расчёт ошибок предсказания
- Обнаружение концептного дрейфа из трендов ошибок
- Отслеживание калибровки (уверенность vs точность)

**Ключевые классы:** `Prediction`, `PredictionEngine`, `PredictionError`

### 5. Система адаптации (`core/adaptation.py`)

**Назначение:** Обновление убеждений на основе ошибок предсказания

**Компоненты:**
- Обучение, управляемое ошибками
- Баланс пластичности vs стабильности
- Обработка концептного дрейфа
- Регулировка скорости обучения
- Измерение восстановления после дрейфа

**Ключевые классы:** `AdaptationEngine`, `ModelAdapter`, `AdaptationEvent`

### 6. Системы памяти (`memory/`)

**Эпизодическая память** (`memory/episodic.py`)
- FIFO буфер (макс 500 опытов)
- Выборка недавних и воспроизведение
- Выборка с приоритетом по ошибкам

**Семантическая память** (`memory/semantic.py`)
- Хранение фактов (субъект→отношение→объект)
- Отслеживание уверенности и стабильности
- Запросы по субъекту/отношению

**Консолидация** (`memory/consolidation.py`)
- Перенос эпизодическая→семантическая
- Извлечение паттернов
- Забывание на основе уверенности
- Управление интервалом консолидации

### 7. Самомодель (`models/self_model.py`)

**Назначение:** Понимание агентом своих собственных возможностей

**Отслеживает:**
- Точность предсказания по задачам
- Оценки уверенности в возможностях
- Охват знаний vs неизвестное
- Уровни ресурсов (энергия, загрузка памяти)
- Рекомендации скорости исследования

**Включает:** Информированные решения об исследовании/эксплуатации

### 8. Планирование (`planner/tree_search.py`)

**Назначение:** Генерация многошаговых последовательностей действий

**Реализация:**
- Поиск дерева с ограничением по глубине
- Расширение ветвей с учётом неопределённости
- Оценка лучшего пути (награда + уверенность)
- Планирование, ориентированное на цель

**Ключевой класс:** `TreeSearchPlanner`

### 9. Механизм любознательности (`core/curiosity_rl.py`)

**Назначение:** Исследовательский драйв, объединяющий несколько сигналов

**Сигналы:**
- Новизна (обратная частота посещений состояния)
- Неопределённость (низкая уверенность предсказания)
- Ошибка предсказания (возможность обучения)
- Расчёт внутренней награды

**Ключевой класс:** `CuriosityEngine`

### 10. Контроллер развития (`core/developmental_stage.py`)

**Назначение:** Отслеживание прогрессии агента через стадии развития

**Стадии:**
1. BLANK → PERCEPTION → ASSOCIATION → PREDICTION → 
2. EXPLORATION → MEMORY → SELF_MODEL → PLANNING → EMBODIMENT

**Отслеживает:** Переходы стадий, требования, появление возможностей

**Ключевой класс:** `DevelopmentalController`

## Цикл агента (за шаг)

```
ВОСПРИЯТИЕ
  ↓
ПРЕДСКАЗАНИЕ
  ↓
СРАВНЕНИЕ (предсказано vs действительно)
  ↓
АДАПТАЦИЯ (обновить модель мира)
  ↓
ПАМЯТЬ (хранение эпизодов + консолидация)
  ↓
САМОМОДЕЛЬ (обновить оценки возможностей)
  ↓
ВЫБОР ДЕЙСТВИЯ (исследование vs планирование)
  ↓
МЕТРИКИ (запись данных шага)
```

## Принципы архитектуры

### 1. Модульность
- Каждая система имеет чёткую ответственность
- Минимальная связанность между модулями
- Чистые интерфейсы

### 2. Воспроизводимость
- Детерминированная с фиксированными семенами
- Сохранение/загрузка контрольных точек
- Экспорт метрик
- Отслеживание версий

### 3. Масштабируемость
- Pure Python (эффективный)
- Конфигурируемые параметры
- Расширяемые интерфейсы
- Легко добавлять новые окружения

### 4. Исследовательский фокус
- Упор на интерпретируемость
- Сбор метрик на каждом шаге
- Доступность параметров
- Ясные причинно-следственные связи

## Конфигурация

Все параметры конфигурируемы при инициализации агента:

```python
agent = TabulaRasaCore(
    seed=42,
    enable_metrics=True,
    verbose=True
)
```

Отдельные системы имеют собственные параметры:

```python
substrate = SensorySubstrate(
    window_size=4,
    entropy_threshold=0.4
)

brain = DynamicSparseGraph(
    learning_rate=0.2,
    decay_rate=0.005,
    pruning_threshold=0.02
)
```

## Производительность

- Один эпизод (100 шагов): ~2 секунды
- Сбор метрик: <5% накладных расходов
- Память на агента: ~50MB
- Масштабируется линейно с длиной эпизода

## Известные ограничения

1. Один агент (нет многоагентного обучения)
2. Только дискретные пространства состояний
3. Детерминированное окружение (для воспроизводимости)
4. Нет ускорения GPU
5. Базовая глубина планирования (3 шага по умолчанию)
