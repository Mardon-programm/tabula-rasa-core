# TR-Core Быстрый старт

## Установка

```bash
cd tabula_rasa_core
pip install -r requirements.txt
```

## Запуск первого эпизода

```python
from main import TabulaRasaCore
from environment.sandbox_sim import SandboxEnvironment

agent = TabulaRasaCore(seed=42, enable_metrics=True, verbose=True)
env = SandboxEnvironment(seed=42)

stats = agent.run_episode(env, max_steps=100)
agent.print_status()
```

## Понимание цикла агента

Каждый шаг выполняет:

1. **Восприятие** - Обработка наблюдения из окружения
2. **Предсказание** - Генерация предсказания следующего состояния
3. **Сравнение** - Оценка точности предсказания
4. **Адаптация** - Обновление модели мира на основе ошибок
5. **Память** - Сохранение эпизода и консолидация знаний
6. **Действие** - Выбор следующего действия (исследование или планирование)

## Ключевые метрики

- **Точность предсказания** - Насколько хорошо агент предсказывает следующие состояния
- **Ошибка калибровки** - Уверенность vs фактическая точность
- **Сигнал концептного дрейфа** - Обнаружение изменений окружения
- **Скорость исследования** - Баланс между исследованием и эксплуатацией

## Конфигурация

Измените инициализацию агента для различного поведения:

```python
agent = TabulaRasaCore(
    seed=42,
    enable_metrics=True,
    verbose=True
)
```

## Сохранение и загрузка

```python
agent.save_checkpoint("my_checkpoint")
agent.load_checkpoint("my_checkpoint")
```

## Экспорт результатов

```python
metrics_file = agent.export_metrics("results.json")
```
