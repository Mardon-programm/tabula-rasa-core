- **Substrate** - Entropy-based perception layer
- **Graph Brain** - Dynamic sparse neural-like associations
- **World Model** - Comprehensive environment representation
- **Prediction Engine** - Forecasting with confidence tracking
- **Adaptation Engine** - Error-driven learning with drift detection
- **Memory Systems** - Episodic storage + semantic consolidation
- **Self-Model** - Metacognitive capability tracking
- **Planner** - Tree search action planning
- **Curiosity Engine** - Multi-signal exploration drive
- **Developmental Controller** - 9-stage progression tracking
